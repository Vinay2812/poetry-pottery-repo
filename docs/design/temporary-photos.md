## Notes for the client

- Every URL above was downloaded to a temp folder and viewed before being accepted; none show people's faces, festive/holiday styling, or non-pottery subjects (unlike some of the previous seed images, e.g. a cake slice used for a planter).
- Exact glaze-colour matches were not always available in the free stock pool (e.g. "Sage Side Plate" and "Storm Grey Soap Dish" are close but not exact). These are flagged above and should be the first to swap for real product photography.
- No pottery-workshop image with visible faces was used for events/about — all wheel/hands shots are cropped to hands and forearms only.
- Redis (`redis-cli -p 6381 flushdb`) was flushed after the SQL updates so the running dev site picks up the new settings/category values immediately.
